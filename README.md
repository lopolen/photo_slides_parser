# Photo Slides Parser

Витягує текст зі слайдів презентацій, збережених як зображення (`.jpg`, `.png` тощо),
і збирає його в один текстовий конспект.

Звичайне розпізнавання читає слайд зверху вниз і зліва направо. Через це текст зі слайдів,
розбитих на кілька блоків, перемішується, а в конспект потрапляє зайве (заголовки, підписи,
скриншоти). Тому в програмі є візуальний редактор: на кожному слайді можна виділити
пронумеровані області, і в конспект потрапить лише їхній текст, у вказаному порядку.

## Встановлення

1. Встановіть [Tesseract OCR](https://github.com/UB-Mannheim/tesseract/wiki) разом з українською
   мовою (`ukr`). За замовчуванням програма шукає його в `C:\Program Files\Tesseract-OCR\tesseract.exe`,
   потім у `PATH`. Інший шлях можна вказати через `--tesseract` або змінну середовища `TESSERACT_CMD`.
2. Створіть віртуальне середовище та встановіть залежності (потрібен Python 3.10+):

   ```powershell
   python -m venv .venv
   .venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

## Запуск

```powershell
.venv\Scripts\python.exe main.py
```

Відкриється редактор зі слайдами з папки `input/`. Файли обробляються в природному порядку
імен (`1.jpg`, `2.jpg`, …, `10.jpg`), тож слайди варто називати їхніми номерами.

### Робота в редакторі

| Дія | Як |
|---|---|
| Додати блок | протягнути мишею по слайду |
| Перемістити / змінити розмір | тягнути блок / його край чи кут |
| Видалити блок | виділити й натиснути `Del` або ПКМ → «Видалити» |
| Змінити порядок | перетягнути рядок у списку праворуч або ПКМ по блоку |
| Взяти розмітку попереднього слайда | `Ctrl+Shift+V` |
| Попередній / наступний слайд | `PgUp` / `PgDn` |
| Масштаб | `Ctrl` + колесо миші, `Ctrl+0` — вмістити у вікно |
| Пересунути зображення | затиснути середню кнопку миші |
| Розпізнати поточний слайд (перегляд) | `Ctrl+R` |
| Скопіювати розпізнаний текст у буфер обміну | `Ctrl+Shift+C` |
| Розпізнати всі слайди та зберегти конспект | `Ctrl+E` |
| Відкрити іншу папку | `Ctrl+O` |
| Відкрити один або кілька файлів | `Ctrl+Shift+O` |

- Номер блоку визначає, в якому порядку його текст піде в конспект.
- Слайд **без блоків** розпізнається повністю, тож розмічати варто лише складні слайди.
- Розмітка зберігається автоматично у файл `regions.json` у папці зі слайдами.

### Швидке розпізнавання одного фото

1. «Відкрити файл…» (`Ctrl+Shift+O`) і виберіть зображення. Можна вибрати кілька файлів з однієї папки.
2. За потреби виділіть блоки.
3. «Розпізнати слайд» (`Ctrl+R`), потім «Копіювати текст» (`Ctrl+Shift+C`).
   У буфер обміну потрапляє чистий текст, без заголовків «Блок N».

Файл можна відкрити й одразу при запуску: `.venv\Scripts\python.exe main.py -i "шлях\до\фото.png"`.
Розмітка такого файлу теж зберігається в `regions.json` поруч із ним. Тому вона використається
й тоді, коли пізніше обробити всю папку.

### Консольний режим

Якщо розмітка вже готова (або не потрібна), можна працювати без вікна:

```powershell
.venv\Scripts\python.exe main.py --cli -i input -o output.txt
```

| Параметр | Опис | За замовчуванням |
|---|---|---|
| `-i`, `--input` | папка зі слайдами або одне зображення | `input` |
| `-o`, `--output` | файл конспекту (**перезаписується**) | `output.txt` |
| `--cli` | працювати в консолі без вікна | — |
| `--regions` | шлях до файлу розмітки | `<input>/regions.json` |
| `--ignore-regions` | ігнорувати розмітку й читати слайди повністю | — |
| `--lang` | мови Tesseract | `ukr+eng` |
| `--psm` | режим сегментації сторінки Tesseract | `6` |
| `--tesseract` | шлях до `tesseract.exe` | автопошук |

Параметри `-i`, `-o`, `--lang`, `--psm` і `--tesseract` працюють і для редактора.

## Формат `regions.json`

```json
{
  "version": 1,
  "slides": {
    "7.jpg": [
      {"x": 76,  "y": 408, "w": 516, "h": 185},
      {"x": 652, "y": 410, "w": 516, "h": 272}
    ]
  }
}
```

Координати задані в пікселях вихідного зображення. Порядок у списку означає порядок читання.
Слайдів без розмітки у файлі немає.

## Структура проєкту

```
main.py                    точка входу
slides_parser/
  cli.py                   аргументи командного рядка, консольний режим
  ocr.py                   підготовка зображення та виклик Tesseract (OcrEngine, OcrSettings)
  pipeline.py              розпізнавання слайдів по блоках і запис конспекту
  layout_store.py          читання та збереження regions.json
  models.py                Region, SlideText
  images.py                пошук і завантаження зображень
  gui/
    main_window.py         головне вікно
    canvas.py              полотно зі слайдом: малювання, вибір і порядок блоків
    region_item.py         напівпрозорий пронумерований блок
    worker.py              розпізнавання у фоновому потоці
```

Логіка розпізнавання (`ocr.py`, `pipeline.py`) не залежить від GUI, тому її можна
використовувати окремо:

```python
from pathlib import Path
from slides_parser import OcrEngine, Region, extract_slide

slide = extract_slide(OcrEngine(), Path("input/7.jpg"), [Region(76, 408, 516, 185)])
print(slide.text)
```

## Якщо щось пішло не так

- Помилки під час роботи редактора показуються у діалоговому вікні.
- Якщо програма аварійно закрилась, подробиці записуються в
  `%USERPROFILE%\.photo_slides_parser\crash.log`.
- Погане розпізнавання часто виправляється тіснішим блоком навколо тексту (без картинок і рамок)
  або іншим `--psm` (наприклад, `4` для тексту в кілька колонок).
